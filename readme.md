# Bootcamp .NET – Deloitte

## Projeto – Dia 01 (Exemplo)

Este repositório contém um projeto **exemplo** desenvolvido no **primeiro dia do Bootcamp .NET da Deloitte**.  
O foco deste projeto é a familiarização com o ambiente .NET, estrutura básica de um projeto e execução de uma aplicação simples via CLI.

> Este projeto possui caráter introdutório e educacional.

---

## Objetivos do Dia 01

- Configurar o ambiente de desenvolvimento
- Compreender a estrutura de um projeto .NET
- Executar uma aplicação console
- Utilizar comandos básicos da CLI do .NET
- Versionar o projeto com Git

---

## Tecnologias Utilizadas

- .NET SDK (6.0 ou superior)
- C#
- Visual Studio ou Visual Studio Code
- .NET CLI

---

## Estrutura do Projeto

```bash
ProjetoExemplo.Dia01
├── Program.cs
├── ProjetoExemplo.Dia01.csproj
└── README.md
```

### Descrição

- **Program.cs**: Arquivo principal da aplicação e ponto de entrada do programa.
- **.csproj**: Arquivo de configuração do projeto.
- **README.md**: Documentação do projeto.

---

## Como Executar o Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/projeto-exemplo-dia01.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd ProjetoExemplo.Dia01
   ```

3. Execute a aplicação:
   ```bash
   dotnet run
   ```
